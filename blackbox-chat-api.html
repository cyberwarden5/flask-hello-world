Blackbox AI Chat API

The Blackbox AI Chat API empowers applications to execute natural language queries and code assist prompts seamlessly. Send any string query and receive instant intelligent responses.

API Endpoint:

https://tooltitan.vercel.app/blackbox?prompt=

How to Use the API

  1. Dispatch an HTTP GET request to the endpoint with your query string appended to the prompt parameter.
  2. Example request URL: https://tooltitan.vercel.app/blackbox?prompt=Your+Prompt
  3. Receive structured JSON containing the AI model's response.

Example Responses

Successful AI Response (200 OK)

{
    "status": "success",
    "http_code": 200,
    "response": "Hello! How can I assist you today?",
    "dev": "@AftabKabir"
}

Connection Exception Response

{
    "message": "Unable to connect to the AI server.",
    "status": "error"
}
