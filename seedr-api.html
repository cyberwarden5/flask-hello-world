Seedr Combo Checker API

The Seedr Combo Checker API is a high-performance verification endpoint for Seedr login credentials. It delivers comprehensive account telemetry including subscription tier, total storage limits, free bandwidth, and geolocation.

Key Capabilities

  • Check the validity of Seedr account combos (email:password).
  • Retrieve detailed storage capacity metrics and active subscription plan types.
  • Free unlimited API query access with optimized response times.

Base URL:

https://tooltitan.vercel.app/

Seedr Endpoint URL:

https://tooltitan.vercel.app/seedr?combo=email:password

How to Use the API

Integration steps for calling the Seedr Combo Checker API:

  1. Prepare a target credential combo in standard email:password format.
  2. Dispatch an HTTP GET request to the designated endpoint:
    3. https://tooltitan.vercel.app/seedr?combo=email:password
  3. Parse the structured JSON payload returned by the server.

Example Responses

Valid Account Response (200 OK)

{
    "status": "success",
    "premium": false,
    "storage": "2.0 GB",
    "package": "NON-PREMIUM",
    "country": "United States",
    "dev": "@aftab_kabirr"
}

Invalid Credentials Response

{
    "message": "Incorrect Email OR Password",
    "status": "error"
}
