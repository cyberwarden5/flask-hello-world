AI Image Generator API

The AI Image Generator API dynamically produces high-fidelity visual assets based on custom text prompts via cloud synthesis models.

Base URL:

https://tooltitan.vercel.app/

API Endpoint:

https://tooltitan.vercel.app/image?prompt=Your+prompt+here

How to Use the AI Image Generator API

Simply provide a descriptive text prompt of your target subject or art style in the query parameter, and the API will return a direct URL to the rendered image asset.

Key Features

  • Unlimited Use: Generate graphics on demand without strict quota limits.
  • High-Quality Output: Clear, detailed cloud-stored image URLs.
  • Easy Integration: Single HTTP GET request structure.

How to Make an API Request

Send an HTTP GET request containing your URL-encoded prompt string:

https://tooltitan.vercel.app/image?prompt=Your+prompt+here

Example Responses

Success Payload

{ "status": "success", "http_code": 200, "url": "https://storage.googleapis.com/image/..." }

Error Payload

{ "message": "Invalid request or prompt", "status": "error" }

Use Cases

  • Generate AI art and custom artwork for digital applications.
  • Create tailored thumbnails, banner elements, or marketing graphics.
